# Gothic Tales VTT 0.8.0


## Manuelle Installation

1. Foundry VTT beenden.
2. `gothic-tales.zip` entpacken.
3. Den enthaltenen Ordner `gothic-tales` nach `Data/systems/` kopieren.
4. Foundry starten und Gothic Tales als Spielsystem auswählen.

## GitHub-Release

- Manifest Adresse Kopieren
- https://raw.githubusercontent.com/striker-sys/gothic-tales-vtt/main/system.json
- Adresse beim Installieren von Spielsystemen eintragen.
- Spielsystem wird automatisch Aktuallisiert oder heruntergeladen.
