# Gothic Tales VTT 0.8.0

Spielbare Demo auf Basis von Version 0.7.19.

## Installation

1. Foundry VTT beenden.
2. `gothic-tales.zip` entpacken.
3. Den enthaltenen Ordner `gothic-tales` nach `Data/systems/` kopieren.
4. Foundry starten und Gothic Tales als Spielsystem auswählen.

## GitHub-Release

- Repository-Inhalt aus dem GitHub-Quellpaket übernehmen.
- Release/Tag `v0.8.0` erstellen.
- Die Datei `gothic-tales.zip` als Release-Asset hochladen.
- Der Dateiname entspricht dem in `system.json` hinterlegten Downloadpfad.
